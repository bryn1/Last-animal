# Last Animal — v0.6.0 (2026-10-28)

Third GA of the full game on both platforms. Everything below is what
changed for a player since v0.5.0 (2026-10-27).

## What shipped

- **You can talk to the creatures.** Press `V` with a creature inside talk
  reach — wild or a living follower — and you say a phrase in your learned
  tongue toward it, and it answers: the reply paints in the dialogue band as
  creature text (its own codon letters and a bond figure), in the same band
  where NPC lines and quest beats appear. A broken bond does not answer; a
  dead player cannot speak (death means death, v0.5.0). This is the DNA
  message subsystem — built since the early increments, parked with no in-
  game caller — running in the live game for the first time (owner ruling
  2026-10-27: "I want tall to creature to be implemented since it is built").
- **Refusals say why.** The speak key rides the v0.5.0 law that every
  unusable press prints its reason: the dialogue band is busy, no creature
  in range, no tongue you know, or no signature — named, never silent.
- **Speaking counts.** A real exchange rides the SAME spoken signal the
  interact path uses: the DNA meter moves and the "Answer in Tongue" quest
  beat advances exactly as before — one mechanism, not a second one.
- **Nothing else changed for a player.** The rest of the v0.5.0..v0.6.0
  range is internal: three clean-code refactor waves with zero behaviour
  change (MC 11431/11432/11433) and the release bookkeeping itself. The
  test battery grew one leg: 49 = 38 positive + 11 negative, grep-measured
  at this tag, and the new `DNA_TALK` leg proves the exchange from two
  independent spawns on the production boot.

## Known limits (stated, not hidden)

- **The talk key is V, not T.** The plan named `T`; `T` is the shipped
  GA zone-travel key since v0.5.0 and rebinding a shipped control needs an
  owner ruling, so speak rides the unused `V`. Named in code, docs and the
  commit — not buried.
- **The reply language is the codon display, and there is no voice.** The
  creature answers as codon letters plus a bond figure — the DNA
  subsystem's own output format — rendered as on-screen creature text. There
  is no spoken audio for the language and no prose translation layer.
- **Talking does not persist.** Nothing new is saved: the tongue and the
  reply are computed live from your existing extraction history, so a save
  keeps no conversation log and creatures hold no memory of what you said.
- **Who answers is a closed list:** wild creatures and living followers.
  Enemies and broken bonds are not conversable at all — the four named
  refusals are the whole contract.
- **Carried from v0.5.0, unchanged:** art is the agreed *direction*, not a
  final quality bar (the D2R-grade ambition is NOT shipped); the icons
  ruling is open (no icons in the game); the engine shutdown-noise line
  class; and the one observed, never-reproduced mid-play crash.
- **Windows evidence is the export gate + owner playtests.** The Windows
  binary passes the PE + embedded-assembly export gates and the owner plays
  the published zips on real Windows; the Linux build host has no wine, so
  no automated Windows render smoke exists — stated, not faked.

## Playtest tips for what's new

- Extraction unlocks the tongue: the same learning that opens Calming Speak
  (3 learned positions, no Manna to speak) unlocks `V`. Until then `V` says
  so, by name.
- In the boot meadow: extract from a few kills, walk near the wild, press
  `V` and watch the dialogue band for the codon reply.

## Provenance

Built from `bryn1/Last-animal` master at the v0.6.0 tag, Godot
4.7.2-stable-mono (hash-pinned engine + export templates, the repo's
`engine/PIN.txt` chain), .NET SDK 8.0.x via `ci/export_check.sh` (both
Windows presets) + `tools/export_windows.sh` + `tools/export_linux.sh` —
the same proven mechanism as v0.4.0–v0.5.0. The cut gate was a SPOT
verdict PASS on the tip (boot + positive runtime + `DNA_TALK` green on two
spawns, mode_sets pairing 36==36, battery 49 = 38 + 11 measured, with a
planted-bad run driving `DNA_TALK` RED by name). The packaged Linux smoke
(`LAUNCH_LINUX_SMOKE: RESULT=PASS`) ran from a clean unzip of the built
zip, not from the build tree; the published Linux zip was re-downloaded and
re-smoked (`PUBSMOKE: RESULT=PASS`). Export logs, the smoke transcripts and
capture PNGs live in `la-work/11587-evidence/out/`.
